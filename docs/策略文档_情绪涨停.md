# 模式 J：情绪涨停 — 策略文档

## 一、策略思路

### 背景

天下无双指标通过分离「涨日成交量」和「跌日成交量」，经平滑处理后得到两条线：

- **正线（多头量能线）**：`EMA(MA(涨量, 3), 3)` — 反映买方力量
- **负线（空头量能线）**：`EMA(MA(跌量, 3), 10)` — 反映卖方力量

当正线运行在负线上方时，说明市场买方力量压过卖方，股价处于多头主导阶段。

### 核心逻辑

情绪涨停是一个 **信号确认 + 涨停共振** 的复合策略：

1. 天下无双指标在近期出现了关键信号（金叉或紫转黄），说明多空力量发生了转折
2. 随后股价出现 **涨停**，这是最强烈的价格确认信号
3. 量能转折 + 涨停共振 = 市场情绪高度一致，后续大概率延续强势

### 操作节奏

```
金叉/紫转黄信号出现 → 涨停日选出 → 次日盘中观察 → 确认后尾盘买入
```

- **涨停当日**：系统自动筛选出符合条件的股票
- **次日盘中**：人工观察两个确认条件
  - **倍量**：成交量较前日放大一倍以上，说明资金持续涌入
  - **没死**：股价未出现大幅下跌（如跌破涨停价 -5%），说明抛压可控
- **次日尾盘**：两个条件都满足时，在收盘前 10-15 分钟买入

## 二、信号定义

### 2.1 天下无双基础计算

```
多 = IF(收盘价 > 前日收盘价, 成交量, 0) / 100
空 = IF(收盘价 < 前日收盘价, 成交量, 0) / 100

正线 = EMA(MA(多, 3), 3)      # 3日均值 → 3日指数平滑，反应较快
负线 = EMA(MA(空, 3), 10)     # 3日均值 → 10日指数平滑，反应较慢
```

**设计意图**：正线用短周期 EMA(3) 对变化更敏感，负线用长周期 EMA(10) 更平滑。当正线快速上穿负线时，说明短期买方力量急剧增强。

### 2.2 金叉信号

```
金叉 = 前日(正线 <= 负线) 且 当日(正线 > 负线)
```

正线从下方穿越负线，代表多头量能开始压过空头量能。

### 2.3 紫转黄信号

天下无双指标中，正线的柱状图有两组颜色：

| 状态 | 条件 | 颜色 | 含义 |
|------|------|------|------|
| 正线上升 | 正 > 0 且 正 > REF(正, 1) | 红底 + 青蓝层叠（黄亮色调） | 多头量能增强 |
| 正线下降 | 正 > 0 且 正 < REF(正, 1) | 棕底 + 紫粉层叠（暗紫色调） | 多头量能衰减 |

```
紫转黄 = 前日正线下降(紫柱) + 当日正线上升(黄柱) + 正线 > 0

即：REF(正,1) < REF(正,2)  且  正 > REF(正,1)  且  正 > 0
```

紫转黄代表多头量能在短暂衰减后重新走强，是一个二次启动信号。

## 三、选股算法

### 3.1 筛选条件

对每只股票依次检查：

**条件 1：当日涨停**
```
日涨幅 = (当日收盘 - 前日收盘) / 前日收盘 × 100%
日涨幅 >= 9.5%
```

**条件 2：近 10 个交易日内出现金叉或紫转黄**

回溯窗口内的每一天，检查是否满足：
- **金叉**：该日正线上穿负线
- **紫转黄**：该日正线从下降转为上升

两个信号只要出现任意一个即可；同时出现则信号更强（双信号加分）。

**两个条件同时满足 → 该股入选。**

### 3.2 评分算法

总分 = 各维度加分之和，满分约 100 分。

| 维度 | 条件 | 加分 | 说明 |
|------|------|------|------|
| **信号新鲜度** | 信号出现在 1-2 天前 | +20 | 信号越新鲜，共振越强 |
| | 3-4 天前 | +15 | |
| | 5-7 天前 | +10 | |
| | 8-10 天前 | +5 | |
| **双信号共振** | 金叉 + 紫转黄同时出现 | +12 | 两个信号互相印证 |
| | 仅出现一个信号 | +5 | |
| **正/负比率** | 正/负 >= 3.0 | +12 | 多头压制空头程度 |
| | 正/负 >= 2.0 | +8 | |
| | 正/负 >= 1.5 | +4 | |
| **涨停量比** | < 1.0（缩量涨停） | +12 | 筹码锁定，抛压极轻 |
| | < 1.5（温和放量） | +8 | |
| | < 2.0（适度放量） | +4 | |
| **历史弹性** | > 80% | +10 | 股性活跃 |
| | > 50% | +7 | |
| | > 30% | +3 | |
| **板块排名** | TOP 5 | +10 | 热门板块助推 |
| | TOP 10 | +7 | |
| | TOP 20 | +3 | |
| **前日涨幅** | > 5% | +8 | 连续强势 |
| | > 3% | +5 | |
| | > 0% | +2 | |
| **MA60 上方** | 收盘 > MA60 | +5 | 中期趋势向上 |

### 3.3 排序与输出

所有入选股票按总分降序排列，取前 10 只展示。

## 四、次日操作规则

入选股票在涨停次日按以下流程操作：

### 观察指标

| 指标 | 达标条件 | 含义 |
|------|----------|------|
| **成交量** | 当日成交量 >= 前日成交量 × 2 | 倍量确认，资金持续涌入 |
| **涨跌幅** | 盘中跌幅不超过 5%（相对涨停价） | 没死，抛压可控 |

### 决策矩阵

| 倍量 | 没死 | 操作 |
|:----:|:----:|------|
| 是 | 是 | **尾盘买入** |
| 是 | 否 | 观望，等站稳再考虑 |
| 否 | 是 | 可小仓试水，不满仓 |
| 否 | 否 | **放弃** |

### 买入时机

- 尾盘 14:45 - 15:00 之间确认条件后买入
- 避免早盘追高，等全天走势确认

### 止盈止损建议

| 操作 | 条件 |
|------|------|
| 止损 | 买入后跌破买入价 -5% |
| 止盈 | 涨幅达到 +20% 以上择机卖出 |
| 持仓 | 一般不超过 10 个交易日 |

## 六、Python 实现要点

### EMA 计算

```python
def _ema(values, period):
    result = [None] * len(values)
    init = sum(values[:period]) / period        # SMA 初始化
    result[period - 1] = init
    k = 2.0 / (period + 1)                      # 平滑系数
    for i in range(period, len(values)):
        result[i] = values[i] * k + result[i-1] * (1 - k)
    return result
```

### 信号检测流程

```
对每只股票:
  1. 计算完整 K 线序列的 正线/负线
  2. 检查当日是否涨停 (涨幅 >= 9.5%)
  3. 回看 10 天:
     - 逐日检查金叉 (正线上穿负线)
     - 逐日检查紫转黄 (正线从降转升)
  4. 涨停 + (金叉 | 紫转黄) → 入选
  5. 计算综合得分并排序
```
