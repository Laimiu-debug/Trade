# F64/F65 全站 AI 入口、快捷提问与显式上下文

## 用户流程

- 顶栏「询问 AI」在各页面可见，打开同一常驻工作台。当前行情数据集/研究运行只有明确选中时才成为待加入来源。
- 单股回测、组合回测、已保存情绪估值结果详情有「带入 AI 核对」。这只交接记录ID并打开工作台；用户仍需点击「加入草稿」，核对截止时间，预览后确认发送。
- 页面交接不自动复制账户事实。选择「同时绑定来源账户」才切换对话范围；目标范围载入自己的草稿，原账户草稿不会复制过去。
- AI 请求运行期间允许切页，顶栏显示运行状态。账户切换/新建切换由主页面阻止；回到工作台可明确停止。页面切换不重复发送、不自动重试。
- 「快捷提问」只准备问题；追加和替换分别需要明确点击。自定义名称、页面、正文、置顶和顺序保存在当前数据目录，随备份恢复；系统项只读复制。

## 来源与截止时间

`PromptContext.artifact_sources` 最多3项，支持 valuation/backtest/portfolio。与原有最多5份行情、10份研究运行、明确账户观察日并存。没有明确选择的记录不会进入请求。

- 估值包含保存的假设、结果、代码摘要、创建时间和结果摘要。假设没有更早历史来源，因此不能将记录创建后的假设放入更早截止时间。
- 单股回测要求任务完成、结果摘要匹配，携带实际参数/执行版本/配置、指标、末尾20笔成交和10个权益点；省略数显式记录。
- 组合回测复用服务端完整输入/检查点/chunk/结果摘要验证，携带冻结样本元数据、配置和指标，以及同样有界的成交/权益片段。
- 完整日线回测产物必须结束于截止时刻之前（上海自然日终边界）。回测明确标注为事后保存计算，不能证明当时选择参数已知；不会把创建后的研究结果伪装成原始历史公告。
- 每份来源另有 `frozen_source_sha256`。预览内容参与原有 input hash；来源、配置、模板或账户修订改变时，准备发送拒绝旧hash。整个上下文仍有120KB限制，不静默截断。
- 模型输出仍为纯文本或既有结构化草稿；快捷入口不接受交易/覆盖人工复盘、不自动应用参数。

## 草稿与并发

- 问题、手动背景、来源IDs、日期、模型通道和模板ID按浏览器内的账户范围+会话隔离。
- 切页保持组件；重新载入后选择已有会话可继续其本机草稿。本机草稿不进入服务端备份。
- 浏览器另一标签修改同一草稿时显示冲突，发送预览失效；明确采用另一份或保留本页继续后才写入。
- 快捷提问列表采用 expected_revision 乐观锁，空列表仍保留版本，避免删除后旧版本再次写入。冲突保留输入，载入最新列表后再提交；审计记录完整前后列表。
- 不保存AI密钥值；模型配置仍使用环境变量引用。无外部模型配置时可管理提示词和本机草稿。

## 实现与接口

- 后端：`ai/quick_prompts.py`、`ai/context_sources.py`、`ai/contexts.py`、`api/ai_context_routes.py`、0059。
- API：GET/PUT `/ai/quick-prompts`、GET `/ai/quick-prompts/history`、GET `/ai/context-sources`；原会话 preview/prepare/stream API不改变授权流程。
- 前端：`ai-launcher.tsx`、`ai-quick-prompts.tsx`、`ai-drafts.ts`、`ai-workspace.tsx`。主页面只有一份常驻工作台。
- 事件：`trade-ai-handoff` 内存缓冲到首次lazy加载完成；`trade-ai-open` 只导航；`trade-ai-activity` 通知主页面运行门禁。

## 边界

- 已保存结果才有可验证ID。独立情绪估值页的未保存即时表单不自动冻结；研究页保存情景结果可带入。
- 不自动拉取全站所有内容，也不将整个无限回测轨迹发送给模型；省略和总体大小限制在预览中可见。
- 本地mock证明工作流，不证明远端模型可用性或投资结论准确率。
