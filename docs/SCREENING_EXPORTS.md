# 冻结筛选结果导出

四步漏斗历史结果与 B1 历史命中都提供 PDF、Excel、CSV。四步漏斗先选择输入池、流动性、图形、量能与风险或最终观察池；导出默认取所选阶段全部证券，也可明确勾选子集。列可以调整，代码和名称始终保留。切换历史记录或阶段会重置导出选择，避免把上一阶段的选择混入新结果。

旧 `ScreenerPage.tsx` 导出对象为选中池全体，带代码、名称与可见列；新版承接这一路径，并补充可核验子集。旧界面未冻结的实时最新价、AI文本或后续手工展示列不会编造成历史结果。B1 导出的是已保存命中，不冒充全部900日输入行情或不命中诊断。

## 格式与精度

- PDF 使用仓库随包字体和 ReportLab 离线生成；宽表按列组分节，证券与序号重复用于关联，长列表分页并重复表头，不截断。
- Excel 包含 `SelectedRows`、列定义、元数据和所选证券来源；数值保存为文本，保留冻结 JSON 的十进制表示，避免 Excel 的15位有效数字上限改变数值。
- CSV 为 UTF-8 BOM，每行带来源运行、阶段、日期、参数、代码/原请求/原结果/选择 SHA、质量与所选行情来源。空阶段仅输出元数据行，证券字段为空。
- 漏斗比例用小数（0.1代表10%）；B1日涨跌幅和振幅用百分数（10代表10%）；金额和价格为元，流通股本为股。B1指标按原扫描存储精度输出，不补造更高精度。空值保持未知。
- CSV/Excel文本的公式前缀加保护，PDF转义所有文本；不会执行证券名称或其他导入文本。

## 冻结范围

只读已有 `ScreenerRun` / `B1Run`，不访问行情服务、不重新计算、不应用当前表单参数。所选证券必须存在于该阶段；请求子集的顺序不改变冻结阶段顺序。导出包含实际参数、截至日期、代码摘要、原请求/结果内容摘要及选择摘要，三个格式使用同一选择摘要。来源日期缺失仍显示未知，不补造成当时已知。

接口：

```text
POST /api/v1/research/screener-runs/{run_id}/exports/{csv|xlsx|pdf}
POST /api/v1/research/b1-runs/{run_id}/exports/{csv|xlsx|pdf}
```

JSON字段为 `stage`、可选 `dataset_ids`、可选 `columns`。B1阶段为 `hits`；漏斗为 `input/step1/step2/step3/step4`。未提供证券列表表示整个阶段；空显式子集、重复证券、越池证券、未知或重复列均拒绝。只读 POST 在线程池执行并沿用本地会话/CSRF保护。

单次最多12000证券，规范化内容24MiB，文件32MiB；超限明确失败并要求缩小选择，不静默裁剪。PDF/XLSX生成需要本机计算资源；这不是后台交易任务，也不发布策略信号。

验证：`backend/tests/test_screener_exports.py`；浏览器 `frontend/scripts/smoke-screener-exports.mjs` 使用真实冻结940根日线创建漏斗及B1记录，验证显式子集的三个下载和选择摘要一致。PDF额外使用50证券长表进行实际渲染、中文文本与完整分页复核。
