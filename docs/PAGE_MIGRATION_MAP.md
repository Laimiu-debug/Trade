- 原提交分别为 `final-trade@2a00ffe7c50b5f023a5db9f1c09ace1683eb1912`、`LaimiuTrade@0953c1d42fe18e808197d6d06df41f1db5e01c94`；原路由文件是 `frontend/src/app/routes.tsx` 与 `frontend/src/App.tsx`。

- 每行列出已运行的专项 smoke 与它验证的行为，运行结论来源于 [功能核对](FEATURE_COMPLETION_AUDIT.md)、[实施记录](IMPLEMENTATION_STATUS.md) 及该行专项验收文档。本次只核对映射和现有证据，没有把脚本文件存在当作重新运行通过。
- 最终全页 [smoke-all-pages.mjs](../frontend/scripts/smoke-all-pages.mjs) 已在 build797 通过 **86 项检查**：实盘/模拟全部导航、展开详情、明暗主题、320px、键盘导航、空态、无页面错误和意外外网请求。原始证据为 `%TEMP%/trade-all-pages-ui-8KuV21/checks.json`。这证明新入口可达和基础交互正常，不单独证明每项业务计算正确。最终发行结果见 [RELEASE_ACCEPTANCE.md](RELEASE_ACCEPTANCE.md)。
