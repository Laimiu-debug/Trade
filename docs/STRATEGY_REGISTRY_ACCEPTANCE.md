# F19 策略启用与默认 / F20 B1 参数预设链

## 入口和设置范围

系统设置 → **策略启用**（`page=settings&settings_group=strategies`）。保留冻结目录的 16 个策略 ID、版本、原启用/默认、说明、能力标记、AI playbook。当前新应用启用状态独立保存，不覆盖旧元数据。

原始迁移版本初始启用 16 项。2026-09-26 扩充独立的 3 项经典参考策略后，新数据目录首次默认启用 19 项，维科夫 V1 仍为默认；已有保存设置不自动开启新增策略。当前目录按策略族和实际执行入口展示，见 [策略整合审查](STRATEGY_CONSOLIDATION_AUDIT.md)。设置属于当前数据目录，随数据库备份。首次 GET 不创建设置记录；保存修订递增，恢复默认也通过填入 → 差异预览 → 确认保存，不删除记录或重置修订。

- 默认必须属于启用集合；全部停用时默认可为空。停用当前默认后，用户必须明确选新默认，不自动替换。
- 新建研究表单采用当前默认。B1 默认明确进入原 B1 多周期工作区；矩阵默认进入冻结池矩阵页签。两者不伪装成单股运行器策略。
- 单股回测与传统组合的默认只有在该入口实际支持时预填；其他默认会保留待选择，不能静默改成另一个策略。
- 已保存研究记录、任务、预设、参数分享和观察信号继续可读。策略停用不是撤销既有信号、删除记录或取消任务。

## 后端执行门禁

`research.registry_service.require_enabled` 是新用户策略提交的统一校验。它只在提交边界读取当前设置，纯计算函数和冻结 worker 不读取实时策略设置。

| 入口 | 新提交校验 | 已冻结执行 |
| --- | --- | --- |
| 固定样本单股研究 / 矩阵插件池 | `create_run` / `create_matrix_run` | 原结果 GET 保留 |
| 单股回测 | `create_backtest` | 配置冻结 admission 摘要；worker/retry 不重新读设置 |
| 多策略扫描 / 信号工作区扫描 | prepare 校验；enqueue 再核对预览修订 | worker / cancel / retry 沿用原冻结输入 |
| 旧内部同步扫描兼容服务 | 创建时校验；HTTP 同步入口原有 409 保留 | 无独立后台步骤 |
| B1 固定样本扫描 | prepare 校验；专用 `save_user_b1_run` 再核对修订 | 内部 `save_b1_run` 为已冻结 TDX 发布入口，不读实时开关 |
| TDX B1 | 入队事务校验，保存 admission | 已排队逐股扫描和最终发布不因后续停用失败 |
| 单股参数平原 / 滚动验证 | 新实验创建校验源策略 | 每点 / 每折 worker 与恢复操作沿用原输入 |
| 传统多证券组合 / 组合平原 / 组合滚动验证 | 新用户创建时校验传统策略 ID | `create_frozen_child` 不读取实时开关 |

四步漏斗、趋势池、事件仓、原始 S1–S9 矩阵及独立事件矩阵是各自的数据/执行路径，不强行映射为 16 个注册策略中的任意开关。界面明确这些范围。正常代码版本/数据摘要校验仍保留：**开关变更**不改变已冻结计算，实际算法升级仍可能触发原有版本不一致保护。

预览与保存绑定设置修订、目录契约摘要和差异内容摘要。保存冲突保留用户编辑，要求重新读取/预览；不能从旧预览直接覆盖别的标签页修改。设置修订历史记录原值、新值和启用变化。

## B1 五参数链

新 `research/b1_params.py` 提供纯 `normalize_b1_params`，固定样本 B1、TDX B1、API 参数模型与参数预设共用。

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| `vol_ratio` | 0.8 | 0.1–1.5 |
| `chg_limit` | 3 | 0.5–10 |
| `amp_limit_10cm` | 5 | 1–15 |
| `amp_limit_20cm` | 8 | 1–20 |
| `kdj_j_upper` | 50 | 10–90 |

保留原扫描公式和 900 根历史门槛。拒绝 NaN/无穷、布尔伪装数值、超界、未知字段。旧通用事件与评分参数在目录中标记只读且说明「B1 扫描未使用」；不能通过预设或 API 伪装为已生效参数。900/60 根预热门槛不能作为可写参数缩短。

B1 页面复用现有 `StrategyPresets`：命名、收藏、版本修订、删除保留历史、`TRADE-PRESET-1` 参数分享码、导入差异、显式填入、人工/AI 参数建议先预览后应用。分享码只包含策略参数，不包含账户、行情、事件模板或交易费用。
