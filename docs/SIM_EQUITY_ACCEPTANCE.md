# F40 模拟资产曲线与 F24 总资产比例换算

## 页面与操作

- 模拟账户 →「模拟资产与回撤曲线」：选择日期范围和每个证券的冻结行情，预览后显式保存。未选行情的持仓保留缺价。页面打开、历史列表和历史详情不会重算估值。
- 策略研究 → 正向观察信号 →「加入模拟委托草稿」→「总资产比例 %（本次买入预算）」：显式选择已保存报告，估算后保存草稿。原「可用资金比例 %」含义不变。
- 总资产比例表示**本次买入预算占总资产比例，预算包含预估费用**。它不表示将某证券最终仓位调至指定比例。按账户实际可支配现金封顶、100 股整手向下取整。
- 保存草稿只保留数量、价格及估算证据；不创建委托、不预留资金、不改变持仓。
- 默认模拟买入须为 100 股的整数倍，手工委托、草稿创建/编辑/预览/提交和实际成交共用校验；不合规的旧待买委托须撤销后重建，旧草稿可改正数量。已有零股持仓允许卖出，历史成交事实保留。

## 冻结和计算口径

1. 初始日与初始资金来源为模拟账户创建审计；旧账户缺少初始日期审计会明确拒绝重放，不猜测日期。
2. 从初始资金重放该账户真实模拟成交的数量、金额及已记录佣金、印花税、过户费。改动当前费用设置不会重算过去费用。重放结果须与当前钱包现金、持仓批次总数量一致，否则报来源冲突。
3. 买卖双方交易所身份均经过中央证券标识规范化；`600000.SH`、`sh600000` 对应同一证券；`sh000001` 与 `sz000001` 不合并。同一证券别名不能选择两份行情。
4. 仅接受用户显式选择、不复权且属于该账户成交证券的行情。每个观察日采用上海日终之前可得、事件日期不晚于该日的最新收盘。旧行情晚到不会覆盖已经可见的较新行情。
5. 严格模式排除缺少 `available_at` 的行情。宽松诊断允许显示，但明确标记可得时间未知，不能据此作为总资产比例分母。
6. 总资产 = 实际现金 + 所有持仓已知市值。任一持仓缺价则总资产、资产指数和该点回撤为空；另保留现金和已知部分市值。陈旧收盘显示具体报价日和标记。
7. 资产指数 = 总资产 / 初始资金。本模拟账本当前无外部出入金功能，因此不是另一个外部资金流调整净值公式。
8. 曲线日期轴为所选可得行情日期、延迟数据首次可得日期、成交日期、范围首尾和月末报告边界的并集。不会补造未知交易日。样本最大回撤以范围起点基线及随后观察的资产峰值为分母；缺价路径使完整样本最大回撤为空，另显示「已观察最大回撤」。这不是全市场逐交易日覆盖保证。
9. 范围从初始日开始时，基线为成交前初始资金；子范围使用前一自然日能观察到的现金及持仓估值。每月变化分母为上一个报告端点资产，显式记录分母/结束日期、资产值和部分月份标记；缺少端点时不计算收益率。

## 保存与并发校验

- 输入冻结账户现金/初始审计、钱包版本、模拟日期、费用配置版本、实际成交及待委托摘要、行情内容 ID 和计算代码摘要。
- POST 预览在读会话中计算。保存再次预览并比较 `expected_input_sha256`，随后短写事务核对钱包版本再插入不可变报告。
- 报告 ID 为冻结请求及完整结果的内容摘要；详情 GET 核对摘要。列表在 SQLite 投影少量元数据，避免反序列化 100 份大曲线。
- 估值历史不会随行情追加、钱包变动、当前费用变化而改写；删除报告保留成交、草稿及已保存草稿证据。
- 总资产比例要求报告结束日等于当前模拟日期、钱包和费用版本一致、期末所有持仓为当日已知报价；缺价、旧价或时间未知均拒绝。
- 保存比例草稿再次计算预算并核对 `expected_quote_sha256`，在同一写事务保留 `SimEquityDraftEvidence`（分母、日期、报告 ID、预算、费用、数量、草稿修订）。同信号已有不同数量/价格草稿会报冲突，不覆盖原草稿。
- 全部接口按模拟账户 ID 隔离。完整报告只读历史不依赖当前账户可写状态。

## 资源边界

- 单次最多 64 个成交证券、64 份行情、60000 根日线、50000 笔实际成交、366 个自然日；结果 JSON 最多 24 MiB。
- 预处理每根行情一次，按本地可得日期分桶。成交/报价游标向前扫描，每个观察日只遍历持仓数量；不按每日期重复扫描全部行情。
- 测试内用 64 × 900 = 57600 根日线、366 个观察日、64 个持仓验证结果和 `<5 秒` 的纯计算上限。此检查不包含行情文件读取、JSON 序列化、数据库写入或 fsync，不是用户机器的响应时间承诺。

## 接口与文件

前缀：`/api/v1/sim-accounts/{account_id}/equity-reports`

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/inputs` | 账户初始日、钱包日期/版本、成交证券和边界 |
| POST | `/preview` | 冻结输入、生成只读预览 |
| POST | 空路径 | 校验预览摘要并保存不可变报告 |
| GET | 空路径、`/{id}` | 轻量历史列表、完整冻结详情 |
| DELETE | `/{id}` | 删除报告，保留原始成交和草稿证据 |
| POST | `/size` | 用完整当前资产报告换算预算 |
| POST | `/drafts` | 校验估算摘要并保存草稿证据 |

实现：`research/sim_equity_domain.py`、`sim_equity_service.py`、`sim_equity_models.py`、`api/sim_equity_routes.py`、迁移 `0055_sim_equity_reports.sql`。

页面：`sim-equity.tsx`，由 `simulation.tsx` 挂载；`research.tsx` 的资产比例换算区。

## 当前边界

- 不接实时行情；报告只使用所选冻结样本。
- 不将陈旧收盘伪装为当前日完整分母，也不补造未知交易日。
- 不自动执行委托、不自动调整目标持仓比例。
- 旧账户缺少可信初始日期审计、账本与钱包不一致时保留原数据并明确报错。
