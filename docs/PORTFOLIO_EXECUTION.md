# 固定研究样本组合执行协议

版本：`fixed-sample-causal-portfolio-shanghai-marks-v2`。本模块是可运行的多证券组合研究，不声明与旧版全部矩阵、传统执行路径数值等价。

## 范围与入口

- 页面：历史回测 → 固定样本组合回测。
- API：`/api/v1/research/portfolios`，包含预览、显式创建、列表、详情、完整证据、JSON 导出、暂停、续跑、取消、重试、软删除。
- 输入：用户明确选择的冻结日线数据集，每个 A 股证券一份，前后缀别名规范化后拒绝重复。
- `universe_scope=fixed_research_sample`；每次保留 `selection_membership_unverified`。每日、每周、实际卖出触发的滚动，也仅在这份固定研究样本内进行。
- `execution_strict` 仅约束行情知识时点。当前不提供宣称历史市场成员完整的严格选项。
- 固定100股整手和 T+1。缺少日线或零成交量日期不模拟成交；未模拟涨跌停封单、分红送股、真实盘口容量。

## 三条独立信号路径

### 原始矩阵 `matrix_raw_s1_s9`

源依据：旧项目 `app/core/backtest_signal_matrix.py::compute_backtest_signal_matrix`。

| 信号 | 实际计算 |
| --- | --- |
| S1 | 20日高低振幅 / 60日高低振幅 < 0.7 |
| S2 | 10日均量 / 60日均量 < 0.6 |
| S3 | 40日收益在当前可用固定样本中的前 N 项 |
| S4 | 20日振幅 / 收盘价 < 0.18，且距 MA20 < 6% |
| S5 | 收盘超过此前20日最高价，且量 > MA20量 × 1.2 |
| S6 | 收盘上穿 MA10，且高于此前10日最低价 |
| S7 | MA10 > MA20 > MA60 |
| S8 | 收盘低于此前20日最低价，或低于 MA20 × 0.97 |
| S9 | 收盘低于 MA10、量 > MA20量 × 1.4，且40日收益为负 |

S1–S4 至少两项成立入池；买入为池内 S5 或 S6，退出为 S8 或 S9。分数为 `(池分 + 2×S5 + 1.5×S6 + S7) / 8.5 × 100`。

日历窗口保留缺失日期，不将停牌缺口压缩成连续交易日；S3 的40日回报仍使用日历端点。完整日历下已逐日对照旧 NumPy 矩阵；同分按规范化证券代码稳定排序，修正旧 `argpartition` 边界并列不稳定问题。

### 传统运行器 `traditional_runtime14`

调用当前共享纯函数 `runtime.evaluate_strategy`，覆盖14个已迁移单股策略。必须同时满足信号和 `draft_eligible` 才能买入；风险观察不能被当作做多信号。

股票池包含当日历史完整、运行器可计算的样本；五龙等策略自己的入池门槛仍由运行器检查。排序优先使用运行器的 `local_score` / `signal_score`，否则使用已有候选评分或40日收益，最后按证券代码稳定排序。维科夫评分不混淆候选分与入场质量。该协议不宣称旧版跨股票混合权重排序等价。

维科夫事件模板在创建时冻结，系统模板修订0可用，过期修订拒绝。传统路径的风险退出仅依据当前主事件属于风险事件；任意已知退出事件使用下面的独立事件矩阵路径。

### 维科夫事件矩阵 `aligned_wyckoff_events`

源依据：旧 `store.py::_build_aligned_backtest_signal_matrix`。参数默认沿用旧组合请求：窗口60、最低入场质量55、最少事件1、默认不要求序列。PS/SC/AR/ST/TSO/Spring/SOS/JOC/LPS 均可配置为积累入场事件；风险事件不能用于做多。退出可选择任意已知事件。未实际应用的排名权重、未知事件、重复事件拒绝。

事件日期必须等于当前前缀的观察日。入场依次检查事件数量、序列、入场质量、健康分、事件分、等级与确认状态，按入场质量排序。S5/S7表示事件买入，S8表示配置的退出事件，其余S值不使用原始价量公式；事件证据中保存所有门槛实际值、拒绝原因和确认状态。

提供两种明确口径：`event`（默认）在启用确认要求时逐个验证入场事件，不能借其他事件的确认授权；`legacy_snapshot` 使用旧版快照整体确认状态用于对照。事件发生日与快照实际观察时间分别保留，未来确认不会回填到先前事件日。同日退出优先于入场，这是对旧矩阵同时置买卖标记的有意修正。

旧事件矩阵的 `in_pool` 表示入场门槛，本模块保存为 `event_gate_passed`；共用股票池保留可计算固定样本，避免延迟2–5日的合法信号仅因次日未重复产生同一事件而被撤销。实际退出事件仍使待买意图失效。两种池概念不会被混称。

## 时间与成交阶段

每个组合日期依次执行：

1. **开盘前知识选择**：只看日期更早、在北京时间09:30前可得的日线。缺少最新组合日历前一日行情则不产生新入场决策；严格模式还要求标的历史前缀完整。未知可得时间在宽松模式保留质量标记，`known_at=null`，不会补造时间。
2. **样本内股票池刷新**：固定、每日、新日历周，或实际卖出之后的下一样本日期。实际卖出不能倒改先前池成员。
3. **开盘退出**：已知风险事件、持有期、日线观察减仓、收盘走弱确认，以及此前预设的开盘跳空止损止盈。完整退出释放持仓名额；部分退出保留名额。开盘退出款可以支付随后买入。
4. **开盘买入**：已有信号之后1–5个标的可观察日线开盘，按候选分和稳定代码排序，受每日前K、总持仓数、单证券资产占比、现金缓冲、整手、费用约束。仓位资产按可观察开盘价和此前估值计算。
5. **盘中预设障碍**：只处理 T+1 可卖库存。止损/止盈触达用日线高低价；同日两者都触达时默认保守止损，可显式选择乐观敏感性对照。此阶段卖出款不能回到当天开盘阶段。
6. **日终记账**：使用截至上海自然日23:59:59.999999（UTC15:59:59.999999）已知的收盘价，记录现金、每个证券数量和估值。上海次日凌晨收到的价格不能进入前日权益。样本末尾保留未平仓持仓，不虚构终端卖出。

实际开盘跳过预设价时，止损按更低开盘、止盈按更高开盘处理，再施加不利滑点。开盘发生的触发不能被后来日内相反极值改写。盘中高低触发没有精确成交时间，导出 `execution_at=null` 和当日交易时段区间，并保留 `intraday_sequence_unknown`。

移动回撤规则观察此前日线低点与收盘是否跌破此前峰值阈值，次日开盘按配置比例整手减仓；收盘连续低于 MA10 达到确认天数时次日开盘清仓。两开关独立；这些是日线观察后的行动，不是分钟级回撤成交。

## 冻结、检查点与资源

数据库保存完整输入日线、参数、代码摘要、事件模板和资源预算；后续原行情文件缺失仍可续跑。每5个样本日期产生一个不可变证据分块，包含新检查点、成交、权益、刷新池轨迹和未成交原因。检查点记录现金、可卖持仓信息、待买意图、弱势计数、峰值、当前池与游标。

共享单CPU公平调度器每次仅执行一个量子。计算子进程不持数据库会话；提交时核对任务状态、执行代号、输入与旧检查点摘要、当前代码，再原子写入分块及新检查点。取消杀掉自有子进程；暂停完成当前量子后停；关机中断保留此前检查点，恢复后显式续跑。成功分块不重算。软删除保留证据，完整导出复核摘要链。

当前边界：64证券、总60000根日线、并集2000日期；冻结输入20MiB；单量子进程输入24MiB、输出4MiB、内存512MiB、120秒；总计算1小时、结果64MiB。内存由 Windows Job Object 或平台对应进程限制实施。

本机实测64证券×900日=57600根、末尾5日：原始矩阵约1.11秒 / 峰值86,069,248字节，维科夫V2约1.62秒 / 峰值87,158,784字节。这是边界测试样本，不是所有行情的性能保证；超预算会失败并保留已有检查点。

分钟真实执行还需要冻结分钟行情、交易时段和可得时间。历史市场成分、退市、复权、盘口与封单模型需要独立证据来源。单股与组合报告使用独立范围标签；未声称兼容旧版任意组合报告包。

## 完整组合报告（0051）

完成的任意组合路径可冻结为 `trade.fixed-sample-portfolio` v1 报告。数据库保存全部输入日线、事件模板、执行参数、初始检查点、原始5日证据分块及摘要链，随数据库备份保留；来源任务删除后仍可查看。目录只读轻量元数据，详情与导出才校验正文。

ZIP固定包含 manifest.json / report.json / report.html / report.xlsx，压缩与解压总量均限16MiB。白名单、摘要、重复成员、重复JSON键、深度、非有限数值与穿越路径检查失败时拒绝；超过大小限制明确拒绝，不截断。导入只保存冻结结果，不执行策略，也不把第三方摘要当作绩效认证。HTML与Excel均从经验证JSON重新生成；导入包内HTML不会执行。HTML转义并使用CSP；Excel防公式注入，长文本按段保存，保留完整字段。

组合比率保留原Decimal精度与摘要，允许有界28位计算结果，不为满足显示格式重写原始绩效。输出包括成交参考价/滑点/费用/时点/阶段/原因、每日现金与持仓、开放持仓、股票池与事件门槛、未成交原因、全部输入日线与检查点。新格式与旧格式没有自动兼容声明。

## 组合参数实验（0056）

从当前算法版本的完整组合结果冻结研究样本，支持完整grid或固定种子的LHS。最多8维、400候选；完整网格超限拒绝，LHS舍入去重不随机补点。候选联合参数全部验证后才能提交。原始矩阵可调S3 top_n，传统14策略仅开放已执行参数，事件矩阵开放实际数值/布尔/枚举门槛；事件集合、模板、历史范围和严格时点口径保持冻结。

支持资金比例、持仓数、持有期、池刷新、每日前K、延迟、止盈止损、滑点、回撤阈值和减仓比例、弱势确认与退出开关。若全部候选都关闭回撤退出或弱势清仓，相应无效维度拒绝。不是分钟减仓参数。

内部候选使用原PortfolioRun执行与原始证据格式，每个公平调度轮转只运行一个候选的5日量子；普通组合队列不执行或展示内部候选。父实验控制暂停、取消、重试与软删除，内部候选不能被普通任务接口独立控制。已完成候选不重跑；代码更新拒绝续跑，不能混合新旧算法。总冻结候选输入上限128MiB，总计算2小时、结果128MiB，同时受单组合与单进程预算限制。独立候选可以生成完整组合报告。

指标按同一证券买入至完整清仓聚合部分卖出腿，未清仓周期不进入胜率/盈亏因子，权益仍含持仓。入场成交率分母为已到期可执行意图，包含TOP_K/持仓上限/资金不足拦截，排除未到期与池/风险失效意图。全点计算完后统一进行两遍评分，提供邻域、敏感度、稳定区域及参数收益相关性；邻域不足不硬造稳定性分。这些都是样本内描述，不能标为OOS。

## 组合 Walk-forward（0057）

候选采样范围在创建时冻结，基于组合日期并集建立扩展训练、可配置gap与不重叠完整测试折。首次训练至少32日期，测试至少10日期，最多12折，所有训练候选与测试阶段合计最多400项；不足完整测试折的尾部明确列出，不混入汇总。每个证券首折训练末日必须有至少32根真实日线。

训练子任务只获得截至训练末日的行情，测试子任务只获得截至测试末日的行情；每阶段重新计算行情摘要。阶段前日线用于信号预热，不产生阶段前成交或收益。训练完成后仅以训练完整持仓周期指标排序并冻结选择SHA；本折测试只运行所选候选。没有达到最低周期数的训练候选时，跳过本折测试并记录原因。未来测试行情冲击不得改变训练输入、训练绩效和所选参数。

测试各折重新初始化资金与仓位，末日未清仓持仓保留估值。按各折收益比例拼接OOS曲线、回撤和完整周期数；不等于连续持仓组合。后续训练可以使用此前已经过去的测试行情。固定样本与人工候选设计的事前独立性限制始终显示。

每阶段继续复用原组合5日量子、过程预算、原始证据和完整报告；总冻结阶段输入128MiB，总计算4小时、结果256MiB。恢复保留原子成功检查点和不可变训练选择；版本更新不能串混。阶段完整报告可以独立导入导出，WF整体JSON包含时间计划、选择证据、阶段摘要及OOS分析。

## 组合高级分析与日终条件计划（0062）

已完成组合可另建持久分析任务，冻结源结果SHA、完整计算输入、分析版本、随机种子与预算。共享CPU调度运行独立子进程，单次120秒、512MiB、输入32MiB、输出16MiB；失败不发布半成品，取消停止自有进程，关机恢复后显式重新计算。目录读取轻量字段；详情核对结果SHA。源任务删除不影响已创建分析，已冻结报告不依赖分析任务仍在目录。

收益基于组合日终权益，含初始资金至首日权益的变化。Sharpe使用日收益总体标准差、Sortino使用全体日收益负部的均方根，年化观察日数252，无风险利率0；Calmar用同口径年化收益/最大回撤。恢复期明确已恢复/尚未恢复。交易期望、盈亏比与连续亏损按买入至完全清仓归并所有部分退出腿，末日未清仓周期单列。最高同时持仓由实际成交序列计算，包含日内持仓峰值。

月收益使用实际覆盖日期，首尾月份可能不完整。周期数不足20与月波动10%对应的惩罚是版本化描述规则，不能称为经验证的评分模型。单次组合没有参数邻域证据，邻域一致性与稳定总分返回未生成，不能填0。参数邻域需另运行组合参数实验。

行情分组使用每笔入场前已可得的该证券20日收益（±3%）作为上涨/震荡/下跌代理，未知归为独立组；它不是全市场牛熊判定。分组收益为完整清仓净盈亏/组合初始资金；分组回撤为已平仓盈亏相加的序列，不复利重叠证券收益，不包含持仓浮亏，不表示可投资分组策略。

Monte Carlo采用组合每日收益的移动区块有放回抽样，不将部分退出腿视为独立交易。每条路径长度等于原观察日期数，保留块内顺序与同时持仓的组合收益，假设块间独立，不保留跨块依赖，不预测未来。种子0至2^32−1，100至2000次，区块1至60日；至少30日收益且3个完整区块，否则输出样本不足。输出抽样收益/回撤p5/p50/p95、归零比例与亏损至少20%比例。数值溢出不丢弃路径后假装有效，而将整组收益分位数标空并记录原因。

用户选定原区间内一个估值日期生成日终持仓、当日成交与条件计划。从截至该日最近的原检查点最多重放4天，重放输入先截断未来日历与行情。再只用上海当日23:59:59.999999之前已可得前缀计算信号；前缀缺失/迟到保持质量标记，宽松未知时间仍为null。未来价格大幅改动不得改变当日条件计划。

条件计划包含当前现金、持仓成本/估值、当日可卖数量、下个交易日T+1条件库存、预设价位情景、已知风险/持有期/弱势退出、部分减仓、待买延迟。下一真实交易日期、开盘价、成交量和买入股数未知，不从未来日线读取，也不按当前收盘假设成交。周刷新是否跨周尚未知时明确保留资格条件；候选排序不等于最终可执行排名，前K/资金/名额只在实际到期时重新校验。多种卖出情景互斥，不能相加数量。源执行代码变化时仍可分析既有权益与成交，但旧计划明确未生成，不混用新执行逻辑重算旧状态。

完整组合报告v2可显式附加已完成、同源SHA的高级分析与所选日计划，JSON/离线HTML/Excel/ZIP全部保留，导入只验证数据不执行计算。v1报告继续兼容；未附分析显示未生成。分析结果属于样本内描述，Walk-forward使用独立训练/测试任务，不在报告中伪造成OOS。

## 可选波段退出（执行版本 v3）

`fixed-sample-causal-portfolio-known-band-exits-v3` 新增四个默认关闭的配置，组合工作台、参数实验和独立实验室共用实际计算：

| 参数 | 条件与执行 |
|---|---|
| `trail_activate` | 已可得持有期最高价相对入场价达到激活比例，且此前收盘低于MA10，下一观察日开盘退出 |
| `time_stop_days` | 入场之后完成的标的观察日线数达到门槛，同时已知最大浮盈小于 `time_stop_min_gain`，下一观察日开盘退出；0关闭 |
| `time_stop_min_gain` | 时间退出要求的最低已知峰值涨幅；时间规则关闭时非零值拒绝 |
| `breakeven_trigger` | 已知峰值涨幅达到门槛后，将保护价提高至入场成交价×1.002；后续跳空按实际开盘价，盘中按预设障碍规则 |

比例采用小数，0关闭相应激活规则；时间门槛为观察日线数。保本价只是价格保护目标，费用和不利滑点仍可使净收益为负。已有退出规则保持原优先级；跳空预设保护先于已知收盘计划，多个日线障碍仍受原保守/乐观敏感性规则约束。

激活只使用开盘前已可得的上一根日线，当前根高点不能先激活保护再反推当前低点成交。入场当日高点在后续确认可得后可参与峰值统计，这是与旧脚本直接跳过入场日极值的明确差异。保护状态、已知峰值、观察日期进入检查点；部分退出不会忘记已激活的保本保护。计划与执行使用同一退出函数。

实验室图形/混合信号可同时冻结 `entry_box_high`，开启 `structural_box_stop`（箱顶×0.95参与保护价取最大值）和 `ma20_box_break`（此前收盘同时低于MA20×0.97、入场箱顶×0.95，次观察日开盘退出）。缺少合法入场箱顶则拒绝该笔入场。生产三条组合信号路径当前没有此箱顶证据，创建接口拒绝这两个开关；不会以动态箱顶或空值冒充结构保护。
