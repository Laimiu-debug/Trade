# 统一分组设置验收

核对日期：2026-09-26。入口：系统设置，`settings_group` URL 参数只接受已知分组，刷新保留当前子页。

## 范围与真实数据流

| 分组 | 范围 / 已有版本来源 | 保存和恢复默认的实际影响 |
|---|---|---|
| 账户费用 | 当前实盘或模拟账户 / 原费用版本 | 调用原费用服务；仅恢复四项费用，模拟现金缓冲、滑点、资金、持仓和旧订单不改写。 |
| 净值目标 | 当前实盘账户 / 原目标版本 | 调用原目标服务；新版本重新计算该账户历史目标节点，保留旧版本。 |
| AI 模型 | 当前数据目录全局 / 原 AI revision | 编辑文本、视觉模型元配置及环境变量名称；默认清空模型地址/名称，不改环境变量值、会话或运行。保存与默认预览均不联网。 |
| 行情来源 | 当前数据目录全局 / 0050 `application_settings` | 保存默认 provider 和实际回退顺序；行情页面进入时读取，临时表单覆盖只作用于该次请求。 |
| 显示与密度 | 当前浏览器 / 本机快照版本 | 明/暗/系统及舒适/紧凑立即生效；恢复前后核对本机版本和实际值，不覆盖其他标签页的新修改。 |
| 本地日历 | 当前数据目录全局 / 原日历 revision | 保存完整本地覆盖；恢复默认留存新 revision 的空覆盖，之后推荐未知，已保存计划日期保持。 |
| 存储与备份 | 当前运行实例 | 内嵌原 `SystemSettings` 与受控生命周期流程。无“恢复默认数据目录”或清空业务数据按钮。 |

业务组恢复默认流程为：读取当前组 → 只读差异预览 → 明确确认。预览摘要绑定组、账户、revision、前值与后值；确认时重新计算并比对。并发变更返回冲突，界面保留草稿，明确采用服务端版本或重新核对后继续。切换分组保留当前页面内草稿；切换账户重新装载该账户组，不能把旧账户草稿写入新账户。

## 行情来源的缺省与幂等

- `/market/online-sync` 与 `/market/sync-jobs` 仅对未显式提供的 `provider` / `provider_order` 使用全局配置。
- 冻结执行体保留来源顺序和应用的设置版本；请求幂等摘要保留调用者原意图与缺省字段标记，不使用可变配置计算身份。
- 相同请求键在全局设置变化后重试仍返回原结果；批量失败重试使用原任务冻结值，不重新应用当前默认。
- 原 `trade-market-provider` / `trade-market-preferred-provider` 不自动迁入、不自动删除。统一设置页可只读预览，确认后另增全局版本。
- 未读取到全局默认时，行情页面拒绝提交联网请求并给出错误，不静默使用旧本机偏好。

## API

`/api/v1/settings/groups/{group}` 支持读取和带 `expected_revision` 的保存；账户组必须指定 `account_id`，全局组拒绝账户参数。另有 `/defaults-preview`、`/reset`、`/preview`、`/audit`；旧来源明确迁入为 `/market_sources/import`。写入沿用 session/CSRF/幂等封装。

配置组协调位于 `api/settings_service.py`，调用已有业务服务；platform 只定义新表，不反向依赖业务域。现有完整备份包含配置与审计。
