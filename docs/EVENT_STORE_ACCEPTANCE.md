# 维科夫事件仓验收

## 本轮交付

入口：`/rebuild.html?page=events`。用户先预览明确的冻结行情、日期、窗口及事件模板版本，再提交耐久回填任务。GET 只读，不触发计算。窗口、模板快照、数据内容和算法摘要共同决定缓存版本；旧结果保持可查。

每次共享 CPU 调度最多计算 10 个同证券时点。子进程限制为 30 秒、512 MiB，任务最多 3000 次判断、累计计算 600 秒、结果 30 MiB；这些是资源上限，不是完成时延承诺。缓存及任务检查点均在数据库内，普通备份包含它们。取消丢弃当前尚未提交批次，已提交缓存保留；继续或重启恢复复用检查点。来源缺失、摘要不符、算法变化及异常分数明确失败，不伪装成无事件。

每个时点只使用该日上海时间 23:59:59 已可得的历史日线。展示发生日、确认状态及观察截至日，历史事件回标日不代表当日已经确认。有效空事件与历史不足单独统计。

当前事件仓提供精确版本读取接口，尚未自动替换扫描和回测计算热路径。界面命中率只统计显式回填任务，不把浏览详情计为计算命中。

## 验证

- `backend/tests/test_event_store_jobs.py`：18 个测试通过，覆盖真实子进程与原纯函数一致、未来极端行情及延后可得时间、配置版本冻结、幂等重叠回填、取消/继续、10/12 检查点重启、超时/内存错误、文件及缓存损坏、备份恢复和只读 API。
- `frontend/src/rebuild/event-store.test.tsx`：4 个测试通过。
- `python scripts/check_rebuild_architecture.py`：通过。
- `frontend/scripts/smoke-event-store.mjs`：真实 Edge 浏览器通过。独立临时数据目录验收显式预览提交、历史观察 90 根排除未来大涨、1 条缓存复用、270 个时点取消后继续、证据详情和 375px 窄屏无横向溢出；不修改用户数据。

## 原实现映射

旧 `app/core/wyckoff_event_store.py` 的版本缓存与 `app/store.py` 的统计/回填迁移为 `research/event_store_*`。计算仍复用已对照原 `SignalAnalyzer` 的 `wyckoff_domain`。新增持久任务和来源校验；原同步循环、运行时统计、异常后空结果行为没有作为新系统可信结果承接。
