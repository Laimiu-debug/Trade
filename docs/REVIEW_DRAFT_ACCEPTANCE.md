# 复盘草稿与冲突保护验收

对应F58；日期2026-09-26。范围是日/周/月/回合正文、次日预案及人工评分评语；AI会话草稿另见 `AI_SHORTCUTS_ACCEPTANCE.md`，人工证券标注另有专用测试。

## 保存与恢复

- 每次输入立即保存本机缓冲；日复盘在正式版本已核对后延迟1.2秒同步，也保留立即保存按钮。周期、回合和人工评分由明确按钮提交正式版本。
- 草稿按账户、日期/周期/稳定回合ID/评分范围与成交ID隔离。切日期、切对象、主导航或重新打开页面时恢复；旧异步响应不能替换新对象、清除新草稿或把旧错误显示在新日期。
- 正式记录接口不可用时，已有本机草稿立即可编辑。正式提交暂停；联网或点击重新读取后核对原revision，冲突必须比较正文并明确采用正式版本或继续本页草稿。
- 日复盘保存过程中仍可继续输入；成功响应仅清除所提交的那份草稿，较新输入保留并衔接成功revision。
- 另一标签页改变同一草稿时停止自动写入，明确选择另一份或本页。保存比较原本机内容，不清除并发新草稿。日复盘真实三标签互改已验证。
- 本机存储写入失败时使用当前应用内存保存输入并显示原因，仍能在该次应用内切页恢复；关闭浏览器前须正式保存或复制保留。不会把内存退路描述成持久保存。
- 页面关闭有未提交内容时提供浏览器离开提示。正式记录和草稿保存状态分开；导出使用正式正文，不伪装成包含未提交文本。

## 边界

本机草稿不进入服务端备份或13组本机显示偏好包；不包含模型密钥。测试的断网是已加载页面的复盘接口失败；没有声称本地服务完全关闭且网页资产未缓存时仍可首次打开应用。损坏草稿不静默删除，保留原存储并显示核对提示。
