# 策略迁移前的口径核对

> **历史阶段记录。** 本文保留迁移当时的判断与证据，其中“尚待迁移”等字样不代表当前状态。完整候选/排名、单股与组合执行现状及本轮整合修复见 [策略整合审查](STRATEGY_CONSOLIDATION_AUDIT.md)；逐项能力见 [功能验收账本](FEATURE_COMPLETION_AUDIT.md)。旧候选公式差异仍需保留，不应因已完成整合而抹平。

2026-09-25，G2 首段。旧版 `relative_strength_breakout_v1` 默认参数和筛选条件位于 `backend/app/core/strategy_registry.py` 与 `backend/app/core/strategy_plugins.py`。同名指标有不同计算入口：

| 指标 | `backend/app/core/screener.py` | `backend/app/store.py` |
|---|---|---|
| `ret40` | `close[-1]` 与 `close[-40]` | 从当前长度回溯最多 40 日的起始收盘价 |
| `retrace20` | 由筛选器内部 K 线计算 | 最近 20 日最高价与最新价 |
| `up_down_volume_ratio` | 最近 20 日上涨 / 下跌成交量之和 | 样本内上涨 / 下跌日平均成交量之比 |
| `vol_slope20` | 加载器与存储路径也各有定义 | 最近 10 日均量对前 10 日均量 |

新应用现在以 `store._build_row_from_candles` 作为相对强弱突破 V1 的候选指标基线，固定样本测试直接调用旧插件的候选过滤与信号判断作对照。研究运行记录固定数据集哈希、算法版本、参数、决策时间和严格可得时间模式。该策略当前完成**单股观察信号**，并提供明确标注为 `next-open-known-prefix-slippage-v3` 的新研究回测路径；它复用模拟交易的费用与成交规则，但未迁移原筛选器入口、评分、策略事件、矩阵与传统回测口径。

B1 多周期扫描已迁入。趋势为王的主策略和三个子策略共用旧版 `trend_king_strategy.py` 的指标及评估函数；新应用将其复制到独立纯计算模块，以冻结 K 线重算，固定样本将指标和模式 A/B/C 结果与旧函数逐字段比较。四个策略各自锁定原模式；可调七个信号阈值，不接受影响旧版事件判断但当前无法计算的其余参数。板块排名和五日板块涨幅缺少同一时点的冻结上下文，指标取旧版中性默认值并标注 `sector_context_unavailable`。指标分不代表旧版最终候选排名；“次日参考价”只是原算法的价格提示，不是保证成交价。当前四策略提供**单股观察信号与统一执行配置的单股回测**；全市场筛选、原排名、策略事件和旧组合回测尚待迁入。

涨停套利已迁入单股冻结样本的“前日涨停 + 今日放量上涨”信号，默认阈值及可调字段取自旧版注册表。固定主板样本的指标和信号评估与旧函数逐字段一致；无板块排名时使用旧版中性值并标记质量限制。旧模块同时包含次日止盈止损评估，而插件会对回测请求设置延迟入场；新应用尚未迁移入出场或旧回测，因此页面中的“当日收盘价”只作为旧信号指标展示，不能作为历史可成交价格。

“主力紫转黄”和“主力金叉”复用旧版 `ths_volume_signal.py` 的纯 K 线计算，分别取 `purple_to_yellow` 与 `golden_cross` 作为插件的触发条件。两个独立固定样本均与旧函数逐字段一致。单股研究不接受这两个策略在旧注册表中用于候选质量 / 事件的参数，因为完整候选路径尚未迁入；指标分仅供查看，不能冒充最终候选排名。

情绪涨停的单股信号已按旧版 K 线量能回溯与涨停共振公式迁入，固定触发样本与原函数逐字段一致。当前只接受当日涨幅、回溯交易日和指标分下限；旧注册表中的“次日倍量 + 没死”确认需要后一交易日数据和独立决策时点，尚未执行，不能作为当前信号已经确认的依据。板块排名缺失时使用旧版中性值并标记质量限制。

五龙聚首已迁入单股五龙形态指标与触发函数，65 根日线以上的固定样本与原函数逐字段一致。新增八项候选过滤采用旧 `store._build_row_from_candles` 单股入口：最近 19 个索引的均线比较、最近两段 10 日均量斜率及样本内全部涨跌量比均保留旧口径。计算只读取决策时已经可得的 K 线；默认值来自目录（部分值与插件独立回退值不同）。`shape_signal` 保存原始形态判断，最终 `signal` 同时要求入池通过，逐项条件及拒绝原因保存在 `universe`。旧版未核对入池的研究记录不能直接创建模拟草稿。全市场 TDX 候选使用不同指标口径，仍待单独对照。输入少于 65 根日线时以数据不足返回，原指标的非有限数在 JSON 中转成 `null`。

主散节奏波的单股波形指标、周期判定、买点与卖出提示已迁入，固定真触发样本与旧函数逐字段一致。21 个计算参数按旧目录类型及边界校验，布尔开关作为布尔值传给原评估公式，页面以可折叠表单展示。当前只输出买点观察信号和卖出提示指标；旧版最终排名、出场执行和回测尚未迁移。

矩阵信号已接入冻结四步漏斗记录的完整输入池，要求原收益窗口为 40 日，排除日期不同的候选，严格模式在 Top N 前排除可得时间未知的候选。保留 `MatrixSignalPlugin` 的代理公式：S1 用回撤而非 ATR，S2 用量能斜率，S4 保留有符号偏离值，S6 保留固定 0.06 边界；S3 入池按 Top N、评分按正收益，分别记录。排名相同保留输入顺序。原输入池、来源摘要、参数和结果持久化；这一路径不包含向量化矩阵引擎和 S8/S9 回测。

维科夫 V1/V2 与 ScoreOnlyRank 已接入 `SignalAnalyzer.calculate_wyckoff_snapshot` 的完整事件、阶段、确认与评分。候选输入使用旧 store 的 ret40 / retrace20 / amplitude20，不使用 TDX 同名指标替代。30 根以前标记数据不足；原分析器内部 25 根门槛不能绕过候选路径的 30 根要求。单股门槛按旧 get_signals 的实际生效值核对；V1 最低分默认 60，ScoreOnlyRank 读取 entry_quality_score。修复旧代码把显式零健康分当作缺失值的问题；主要关键事件要求确认时，必须检查该事件自身的确认状态。

事件模板、信号发生日、决策时间与当时确认状态全部写入不可变结果。风险或非买入主事件可以是观察结果，但不能提升为买入草稿。ScoreOnlyRank 的单股分数不声称股票池排名。三种策略进入共同 runtime 后，与其余 11 个单股策略共用逐日扫描及统一单股执行配置；B1 与矩阵保留独立扫描入口。旧向量化矩阵、最终排名、全组合传统回测仍待完整对照。

信号篮子的 legacy_signal_anchor 模式保留旧版信号后第 N 根日线收盘目标；complete_overnights 模式以各自入场日加 N 根计算。原版会把涨停买价压到涨停阈值；重构版保存真实样本开盘价，并明确未验证涨停流动性。原始观察收益与可满足 T+1 且计费的收益分别统计，缺数据不用零补齐；这不是账户组合净值。
