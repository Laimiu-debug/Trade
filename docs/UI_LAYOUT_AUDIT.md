日期：2026-09-26。依据用户三张实际截图、两个原项目源码与重构版全部前端入口。本次直接改造页面和交互，并保留已有后端数据、策略 ID、任务及报告。

## 页面与入口

- **策略研究**：策略目录、选股筛选、区间扫描、策略交叉验证、事件模板、单股研究、单股回测、组合回测、参数实验、组合分析与计划、报告库，共 11 个子页面。
- **组合回测**：配置、任务历史、运行结果分别展示。配置分为样本与日期、信号策略、资金与执行、退出与费用、预览提交五步；预览仍绑定实际冻结输入，修改配置会使旧预览失效。
- **参数实验**：单股收益平原、组合收益平原、单股 Walk-forward、组合 Walk-forward 独立选择。
- **报告库**：单股、组合、旧报告分别浏览，保留已有导入导出与详情能力。
- **行情样本**：样本与图表、导入样本、在线同步、数据质量四个子页面。
- **模拟交易**：持仓与下单、委托与结算、策略草稿、持仓估值、成交与复盘、账户恢复分开展示；只读恢复点使用相应历史页面。
- **统计分析**：独立主导航，包含周期收益、交易统计和交易回合；总览保留资产概览和快捷入口。
- **市场资讯**：按条展示标题、来源、时间、摘要；主题链接颜色统一，重复标题摘要不再显示两遍。

## 路由和状态规则

研究采用 `page=research&research=<子页>`；实验/报告模式用 `research-mode`，明确来源用 `research-source`。旧 `page=backtest`、研究 `run`、任务中心 `task` 深链继续解析到对应工作区。行情和模拟子页分别使用 `market-view`、`simulation-view`。

研究仅按需挂载访问过的子页，当前只显示一个；在同一账户内切换研究、行情或模拟子页，保留当前会话表单。刷新或离开整个工作区后的未保存配置不宣称持久化。已提交任务在后端继续运行，结果由任务中心/历史重新进入。

交易、资金、资产快照属于具体账户：切换账户时明确清空这些未提交表单，并显示提示。旧账户迟到的读取响应不能覆盖当前账户事实；已经发出的保存仍属于发起保存时的账户。

## 统一样式修复

- 所有原生文本输入、选择框、文本域均采用同一主题颜色、边框、圆角、焦点与禁用状态，不依赖页面是否使用 `Field` 包装。
- 普通字段标签位于控件上方，复选框保持同行；表单列使用 `minmax(0, 1fr)`，窄屏改为单列。
- 开户名称与两个创建按钮分成明确区域，窄屏按钮纵向排布。
- 补齐此前只有类名而没有样式的区块标题、按钮组、次级面板、标签、JSON 区域；长说明换行。
- 桌面主导航可独立滚动，表格在自身容器横向滚动；键盘焦点与减少动态设置保留。
- 色值仍来自 `docs/design-tokens.json` → `tokens.generated.css`，不新增另一套调色板。
